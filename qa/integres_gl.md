# Exercices intégrés — relecture (galicien)

À vérifier par un locuteur natif : phrases naturelles, formes correctes, consignes cohérentes, aucune réponse ambiguë.


## A1


### Complète (trous entre crochets)

- [Non] me [gusta] o café. — étiquettes : non, dez, gusta — _Je n'aime pas le café._
- Pode falar [máis] [amodo?] — étiquettes : dous, amodo, máis — _Pouvez-vous parler plus lentement ?_
- [Onde] [está] a praia? — étiquettes : onde, traballo, está — _Où est la plage ?_
- [Hoxe] [vai] bo tempo. — étiquettes : hoxe, vai, sete — _Il fait beau aujourd'hui._
- Mañá [teño] unha [reunión] — étiquettes : reunión, tedes, teño — _Demain j'ai une réunion_
- [Onde] [están] os servizos? — étiquettes : están, onde, metro — _Où sont les toilettes ?_

### Transforme

- Change de personne : ti : Hoxe estou moi canso. → **Hoxe estás moi canso.**
- Change de personne : el / ela / vostede : Busco a rúa Colón. → **Busca a rúa Colón.**
- Change de personne : ti : Mañá teño unha reunión → **Mañá tes unha reunión**
- Change de personne : ti : Vivo nun piso pequeno. → **Vives nun piso pequeno.**
- Change de personne : el / ela / vostede : Non falo moito español → **Non fala moito español**
- Change de personne : el / ela / vostede : Non entendo. → **Non entende.**
- Change de personne : ti : Non entendo. → **Non entendes.**
- Change de personne : el / ela / vostede : Hoxe estou moi canso. → **Hoxe está moi canso.**
- Change de personne : ti : Vivo nun piso pequeno. → **Vives nun piso pequeno.**
- Change de personne : el / ela / vostede : Mañá teño unha reunión → **Mañá ten unha reunión**
- Change de personne : ti : Busco a rúa Colón. → **Buscas a rúa Colón.**
- Change de personne : ti : Quero un café con leite → **Queres un café con leite**

### Réponds

- « Falas galego? » — Réponds que tu en parles un peu. → Si, falo un pouco. / Falo un pouco de galego. / Si, un pouco.
- « Algo máis? » — Dis que c'est tout. → Non, nada máis, grazas. / Non, iso é todo, grazas. / Nada máis, grazas.
- « De onde es? » — Dis que tu es français(e). → Son francés. / Son de Francia. / Son francesa.
- « Bos días, que tal? » — Salue et dis que ça va bien. → Bos días, moi ben, grazas. / Moi ben, grazas. / Ben, grazas.
- « Son dez euros. » — Demande si tu peux payer par carte. → Podo pagar con tarxeta? / Pódese pagar con tarxeta? / Aceptan tarxeta?
- « Perdoe, sabe onde está a praza? » — Tu ne sais pas : excuse-toi. → Síntoo, non o sei. / Perdoe, non o sei. / Non o sei, síntoo.
