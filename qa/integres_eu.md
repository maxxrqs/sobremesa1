# Exercices intégrés — relecture (basque)

À vérifier par un locuteur natif : phrases naturelles, formes correctes, consignes cohérentes, aucune réponse ambiguë.


## A1


### Complète (trous entre crochets)

- Paella [asko] gustatzen [zait] — étiquettes : zait, asko, utobusa — _J'aime beaucoup la paella_
- Bihar [bilera] [bat] dut — étiquettes : bat, gazta, bilera — _Demain j'ai une réunion_
- Tren [geltokia] hemendik [gertu] dago? — étiquettes : hondartza, gertu, geltokia — _La gare est près d'ici ?_
- Egunero [metroa] hartzen [dut.] — étiquettes : metroa, dut, hondartza — _Je prends le métro tous les jours._

### Transforme

- Change de personne : hari : Paella asko gustatzen zait → **Paella asko gustatzen zaio**
- Change de personne : hark : Egunero metroa hartzen dut. → **Egunero metroa hartzen du.**
- Change de personne : hark : Egunero metroa hartzen dut. → **Egunero metroa hartzen du.**
- Change de personne : zuri : Paella asko gustatzen zait → **Paella asko gustatzen zaizu**

### Réponds

- « Euskaraz hitz egiten duzu? » — Réponds que tu en parles un peu. → Bai, pixka bat egiten dut. / Euskaraz pixka bat hitz egiten dut.

- « Kafea nahi duzu? » — Accepte poliment. → Bai, eskerrik asko, pozik. / Bai, mesedez.

## B2


### Complète (trous entre crochets)

- [Lanpostu] hori onartu [izan] balu, orain Madrilen biziko litzateke. — étiquettes : izan, lanpostu, urehun — _S'il avait accepté ce poste, il vivrait maintenant à Madrid._
- [Lau] pertsonarentzako mahai bat erreserbatu [dugu.] — étiquettes : urehun, dugu, lau — _Nous avons réservé une table pour quatre personnes._
- [Asko] [ikasi] bazuen ere, ez zuen azterketa gainditu. — étiquettes : ikasi, asko, utobusa — _Bien qu'il ait beaucoup étudié, il n'a pas réussi l'examen._
- Paella [asko] gustatzen [zait] — étiquettes : rroza, zait, asko — _J'aime beaucoup la paella_
- [Kontua] eskatu [nahiko] nuke — étiquettes : nahiko, talde, kontua — _Je voudrais demander l'addition_
- Aurrekontua [mugatua] denez, proiektua [atzeratu] beharko dugu. — étiquettes : mugatua, bulego, atzeratu — _Étant donné que le budget est limité, nous devrons reporter le projet._

### Transforme

- Change de personne : zuk : Tren txartel bat erosiko dut. → **Tren txartel bat erosiko duzu.**
- Change de personne : hura : Pisu bat bilatzen ari naiz erdigunetik gertu → **Pisu bat bilatzen ari da erdigunetik gertu**
- Change de personne : zuri : Paella asko gustatzen zait → **Paella asko gustatzen zaizu**
- Change de personne : hark : Frantsesez eta ingelesez hitz egiten dut → **Frantsesez eta ingelesez hitz egiten du**
- Change de personne : hark : Kafesne bat nahi dut → **Kafesne bat nahi du**
- Change de personne : zu : Goiz jaikitzera ohitu naiz. → **Goiz jaikitzera ohitu zara.**
- Change de personne : hark : Kontratu berri bat behar dut → **Kontratu berri bat behar du**
- Change de personne : hura : Gaur oso nekatuta nago. → **Gaur oso nekatuta dago.**
- Change de personne : hark : Tren txartel bat erosiko dut. → **Tren txartel bat erosiko du.**
- Change de personne : hark : Frantsesez eta ingelesez hitz egiten dut → **Frantsesez eta ingelesez hitz egiten du**
- Change de personne : zuk : Gaur goizetik buruko mina daukat. → **Gaur goizetik buruko mina daukazu.**
- Change de personne : zu : Pisu txiki batean bizi naiz. → **Pisu txiki batean bizi zara.**

### Réponds

- « Etxetik lan egitea hobea dela uste dut. Zuk zer uste duzu? » — Donne une opinion nuancée. → Araberakoa da, baina nire ustez abantailak eta desabantailak ditu. / Ez nago guztiz ados, abantailak ditu baina baita eragozpenak ere.
- « Zergatik iritsi zinen berandu bilerara? » — Explique que ton train a été annulé. → Nire trena bertan behera utzi zutelako, eta hurrengoaren zain egon behar izan nuen. / Trena bertan behera utzi zuten. / Berandu iritsi nintzen trena bertan behera utzi zutelako.
- « Zergatik utzi zenuen zure aurreko lana? » — Explique que tu cherchais de nouveaux défis. → Erronka berrien bila nenbilelako utzi nuen. / Erronka berriei aurre egin nahi nielako.
- « Zer egingo duzu bihar? » — Dis que tu vas travailler puis dîner avec des amis. → Lan egingo dut eta gero lagunekin afalduko dut. / Bihar lan egingo dut eta gero afalduko dut lagunekin.
- « Nongoa zara? » — Dis que tu es français(e). → Frantsesa naiz. / Frantziakoa naiz.
- « Egun on, zer moduz? » — Salue et dis que ça va bien. → Egun on, oso ondo, eskerrik asko. / Oso ondo, eskerrik asko.
