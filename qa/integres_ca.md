# Exercices intégrés — relecture (catalan)

À vérifier par un locuteur natif : phrases naturelles, formes correctes, consignes cohérentes, aucune réponse ambiguë.


## A1


### Complète (trous entre crochets)

- Avui [estic] molt [cansat.] — étiquettes : estàs, estic, cansat — _Aujourd'hui, je suis très fatigué._
- Vull un cafè [amb] [llet] — étiquettes : llet, amb, en — _Je veux un café au lait_
- [Visc] en un pis [petit.] — étiquettes : viuen, petit, visc — _J'habite dans un petit appartement._
- [Hola,] [soc] francès. — étiquettes : hola, set, soc — _Bonjour, je suis français._
- [Agafo] el metro cada [dia.] — étiquettes : agafes, agafo, dia — _Je prends le métro tous les jours._
- Avui [és] [dilluns.] — étiquettes : dilluns, és, sou — _Aujourd'hui, c'est lundi._

### Transforme

- Change de personne : tu : Visc a València → **Vius a València**
- Change de personne : tu : Demà tinc una reunió → **Demà tens una reunió**
- Change de personne : tu : Vull un cafè amb llet → **Vols un cafè amb llet**
- Change de personne : tu : Agafo el metro cada dia. → **Agafes el metro cada dia.**
- Change de personne : tu : Avui estic molt cansat. → **Avui estàs molt cansat.**
- Change de personne : ell / ella / vostè : Busco el carrer Colón. → **Busca el carrer Colón.**
- Change de personne : ell / ella / vostè : Vull un cafè amb llet → **Vol un cafè amb llet**
- Change de personne : tu : Visc en un pis petit. → **Vius en un pis petit.**
- Change de personne : ell / ella / vostè : Agafo el metro cada dia. → **Agafa el metro cada dia.**
- Change de personne : tu : Demà tinc una reunió → **Demà tens una reunió**
- Change de personne : ell / ella / vostè : Busco el carrer Colón. → **Busca el carrer Colón.**
- Change de personne : tu : Avui estic molt cansat. → **Avui estàs molt cansat.**

### Réponds

- « Bon dia, com va? » — Salue et dis que ça va bien. → Bon dia, molt bé, gràcies. / Molt bé, gràcies. / Bé, gràcies.
- « Són deu euros. » — Demande si tu peux payer par carte. → Puc pagar amb targeta? / Es pot pagar amb targeta? / Accepten targeta?
- « D'on ets? » — Dis que tu es français(e). → Soc francès. / Soc de França. / Soc francesa.

## B2
